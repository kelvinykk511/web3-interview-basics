# Oracle 操控／CEX 計價邊界

（銜接：[Oracle vs CEX 報價引擎](./oracle-chainlink-vs-cex.md)——那邊講可信喂價模型；本篇講 **操控面** 同 CEX 產品／Treasury 邊界。）

## 人話（從你熟的 CEX）

CEX 強平／標記價怕「薄盤口被掃一筆就假摔」——所以有指數價、標記價、權重、異常檢測。鏈上亦有同類攻擊面：對手用 **薄流動性池 + 閃電貸** 喺同一個（或極短）區塊內把 DEX spot／拙劣 TWAP 打歪，觸發借貸清算、贖回、或錯誤抵押率。

重點一句：**協議清算信嘅係 on-chain oracle／讀價路徑；你交易所嘅 mark／index 唔會自動救到鏈上倉位。** 上市相關產品、Treasury 碰 DEX、或監控「DeFi 連動」風險時，要分清邊個價會真正扣抵押。

## 面試短答

- **操控典型路徑**：在流動性淺嘅 AMM 大買／大賣 → 瞬間 spot 偏離 → 若協議用「當下 pool 價」或過短 TWAP 窗口 → 清算／鑄造／贖回被錯誤觸發；閃電貸令攻擊者唔使自有本金，同一筆 tx 借→操價→套利／清算→還款。
- **防禦（協議側）**：去中心化 oracle（多源聚合）、夠長且抗操縱嘅 TWAP、心跳＋**deviation** 更新、staleness 檢查、借貸側清算折扣／緊急暫停；唔好直接 `getReserves` 當公允價。
- **CEX mark／index ≠ 協議清算價**：內部價用於合約／統一帳戶風控；鏈上倉位／金庫互動以協議讀到嘅 oracle 為準。兩邊可短暫脫鉤——脫鉤時警報，唔好用 CEX 價「覆寫」鏈上結果。
- **CEX 邊界**：上架「收益／抵押與某 DeFi 相關」產品、或 Treasury／做市碰薄池時，要評估 **oracle 設計 + 池深度 + 歷史操控事件**；監控同時睇 CEX 綜合指數同鏈上 last oracle／池價偏離。

## 常見追問（連答案）

**Q：點解「用 Uniswap 即時價」做借貸抵押危險？**  
A：AMM spot 可由單筆大單（加閃電貸）在同一區塊內任意推歪（深度足夠就成本高，薄池就好平）。清算機器人若跟呢個價，會錯誤清算健康倉或放過壞帳。較穩：Chainlink 類聚合、或長窗口 TWAP（仍要防持續單邊操控同 stale）。

**Q：TWAP 係咪就安全？**  
A：唔係絕對。窗口太短 ≈ spot；窗口長但仍可被持續推價（成本＝維持偏離×時間×流動性）。要睇池深度、窗口長度、同有冇外部 oracle 交叉。面試講「TWAP 提高成本，唔等於免疫」。

**Q：Flash loan 攻擊同「價格預言機」有咩關係？**  
A：閃電貸本身往往唔係漏洞，而係 **同一原子交易內嘅便宜槓桿**。若讀價可被同交易內操價影響，攻擊者借大錢操價→觸發錯誤狀態機→獲利還貸。修的是 **讀價與業務邏輯**，唔係「禁止閃電貸」口號。

**Q：CEX 已經有標記價，點解仲要理 Chainlink／池價？**  
A：你若只做中心化合約，標記價夠；一旦(1) 協議清算決定鏈上抵押品結果、(2) 你們產品結算掛鉤協議、(3) Treasury 在 DEX／借貸放資金——**結算真相在鏈上**。標記價做預警同對沖；鏈上 oracle／協議狀態做「錢係咪已經冇咗」。

**Q：Staleness + deviation 檢查面試點講？**  
A：讀 `updatedAt`／round：超過 max age → 當失效（暫停借貸／清算視協議）。Deviation：新價相對上次移動超過閾值先上鏈，減少 gas 亦避免微噪；但急行情可能短暫「未更新」——同 CEX「指數源延遲」類似，要有熔斷同備用源，唔好 silently 用過期價做大額決策。

## 小練習

**題：** 某山寨幣借貸協議用「該幣／ETH 在單一薄池嘅 2 分鐘 TWAP」做抵押價。CEX 該幣指數 1 小時內穩喺 $1.00；鏈上某塊出現閃電貸把池價打到 $0.40 再恢復。問：(1) 協議可能發生咩？(2) 你哋若有「該幣理財／對外顯示 DeFi APY」或 Treasury 有存款，值班點做？(3) 一句話點向面試官對比 CEX 標記價？

**參考答案：**  
(1) TWAP 被拉低（視取樣）→ 抵押率「惡化」→ 健康倉被清算／壞人低價買抵押；或反向操高用來借過多資產。  
(2) 立即分開儀表：CEX 指數 vs 鏈上 oracle／TWAP vs 協議總鎖倉；暫停或限額相關充提／申購；Treasury 評估能否緊急撤出；唔好用內部 $1.00 假設鏈上倉位仍安全。  
(3) 「CEX mark 反映綜合流動性同風控規則；呢個協議嘅清算鍵係薄池 TWAP——操控成本低，所以 mark≠liquidation truth。」
