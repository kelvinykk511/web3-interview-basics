# Web3 Interview Basics（新手向）

給 Java 後端轉型 Web3 的面試溫習庫。**從零開始**，先講清楚概念，再慢慢加深。

## 目錄（建議順序）

| 目錄 | 主題 |
|------|------|
| `01-blockchain-basics/` | 區塊鏈是什麼、區塊、共識 |
| `02-crypto-wallets/` | 錢包、公私鑰、地址 |
| `03-ethereum/` | 以太坊、Gas、賬戶 |
| `04-smart-contracts/` | 智能合約、Solidity 入門概念 |
| `05-defi/` | DeFi 常見名詞 |
| `06-security/` | 常見安全坑（入門） |
| `07-web3-backend/` | 後端常做什麼（節點、索引、簽名） |
| `sessions/` | 每日短溫習 |

## 約定

- 繁體中文、白話優先
- 每個主題：一句人話 → 面試怎麼答 → 一個小問題
