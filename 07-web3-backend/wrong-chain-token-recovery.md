# 錯鏈 / 錯幣充值找回流程

## 人話
EVM 鏈地址格式一樣，用戶好易「選錯網絡」（例如 BSC 嘅 USDT 打去你 ETH 充值地址）。幣**冇消失**，只係落咗你同一把私鑰喺另一條鏈嘅地址，系統冇監聽所以冇入帳。

## 面試短答
分情況：同私鑰可控（EVM 同地址、自管熱錢包）→ 可找回；地址係合約錢包 / CREATE2 forwarder 而目標鏈未部署 → 可能要喺目標鏈用同 salt 部署先取到；不支援嘅幣/鏈或 MPC 無該鏈支持 → 可能無法找回。流程：工單 → 鏈上核實 tx 同地址屬我哋 → 風控（制裁/黑名單）→ 多簽審批 → 從該鏈轉出 → 入帳並收手續費 → 記帳審計。

## 常見追問
- **Q：點解唔自動入帳？** A：無監聽、無定價/上幣審核、要人手簽名，自動化風險高；量大先考慮加監聽。
- **Q：目標鏈冇 gas 點轉？** A：由 gas 站先打少量原生幣入嗰個地址。
- **Q：帳本點記？** A：獨立「找回」流水，唔當普通充值；扣找回費；全程留審批記錄。
- **Q：Memo/Tag 漏填（XRP/TON 等）？** A：幣落咗共用地址，靠 txHash + 用戶證明匹配，人工入帳。

## 小練習
題：用戶把 Arbitrum USDC 打去你 Ethereum 充值地址（EOA 熱錢包派生），點處理？
答：核實 Arbitrum 上 tx 收款地址屬我哋派生 → 同私鑰喺 Arbitrum 都控制 → 打 ETH gas → 多簽審批轉去歸集地址 → 扣找回費後入用戶 USDC 帳。若係未部署嘅 CREATE2 地址，要先喺 Arbitrum 用同 factory/salt 部署（factory 地址要一致）。
