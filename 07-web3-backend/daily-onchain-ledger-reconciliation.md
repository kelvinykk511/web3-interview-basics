# 每日鏈上 vs 帳本資產對帳

## 人話（從你熟的 CEX）

每日（或每小時）對一次：**條鏈上真係有幾多** 同 **帳本話我哋應該有幾多**。按 **鏈 × 幣** 分開對，差額要分類解釋；解釋唔到就係事故，唔好當「小誤差」拖過去。

## 對帳公式（同一快照點）

**鏈上可控餘額**（熱 + 溫 + 冷 + 未歸集充值地址 + gas 站）  
**+** 已確認未入帳充值的反向調整  
**−** 已廣播未確認出金  
**≈** 用戶負債 + 平台自有資金（手續費收入、gas 預算、做市倉）

兩邊必須用**同一個快照點**：

- **鏈上**：固定 **block height**（`eth_getBalance`／`balanceOf` 帶 `blockTag`；歷史高度要 **archive node** 或自建 **indexer**）。
- **帳本**：同一時間點 **cut-off**（freeze ledger snapshot），唔好用「而家 latest」對「五分鐘前 cut-off」。

## 兩層對帳

1. **餘額對帳（balance）**：鏈上總可控 vs 帳本總負債 + 自有；快，適合每日告警。
2. **流水對帳（transaction / logIndex ↔ ledger entry）**：每筆鏈上 tx／event 對應帳本分錄；**流水對到先知差喺邊筆**。淨餘額對平但兩邊都有錯、相互抵消嘅情況，只對 balance 會漏。

**百萬充值地址唔可能逐個 `balanceOf`：** 用 indexer **增量** = 上期餘額 + 流入 − 流出；再對**有變動**或**抽樣**地址用 `balanceOf` 校驗，防 indexer 漂移。

## 面試短答

- 按 **chainId × asset** 獨立對帳；差額要歸類（在途、gas、無主充值、手動調帳…）。
- 設 **容忍閾值**（按幣價值，dust 可忽略但要 audit trail）。
- **鏈上 < 帳本** 且解釋唔到 → **P0**，暫停該 **鏈 × 幣** 出金，查盜竊／漏記出金。
- **鏈上 > 帳本** 多數係無主充值／空投 → 入**暫記帳**等認領，**唔好直接當收入**。
- 對帳結果要**可追溯**：快照 block height、RPC 來源、腳本版本、cut-off 時間。

## 常見差額來源

| 類型 | 說明 |
|------|------|
| 時間差 | 在途出入金：已廣播未確認出金、已上鏈未入帳充值 |
| Gas 冇入帳 | 出金／歸集燒 native 幣；L2 仲有 **l1Fee** |
| 無主充值 | 漏 memo、錯幣、打到合約地址、空投垃圾幣 |
| Dust／假 token | 非白名單 token 餘額混入掃描 |
| 穩定幣黑名單／銷毀 | USDT `destroyBlackFunds` **冇 Transfer 事件**，要靠 `balanceOf` 發現 |
| Rebasing／fee-on-transfer | 到帳數同 log 唔一致 |
| 手動調帳 | 帳本改咗但冇對應鏈上 tx |
| 熱錢包被盜 | 扣除所有可解釋項後仍 **鏈上少** |

## 處理流程（概要）

1. 跑 balance 對帳 → 超閾值開 ticket。
2. 分類：在途、gas、暫記帳、已知調帳…
3. 解釋唔到 → 升級 P0 + 停出金 + 流水鑽取。
4. 鏈上多 → 暫記帳；鏈上少 → 優先懷疑出金／gas／被盜。

## 常見追問（連答案）

**Q：點解要固定 block height？**  
A：唔同節點、唔同時間讀 `latest` 會飄；在途 tx 令「鏈上而家」同「帳本 cut-off」永遠對唔齊。固定 height + 帳本同一時刻 snapshot 先可比。

**Q：點解唔可以只對餘額？**  
A：定位唔到邊筆錯；兩筆相反方向嘅錯可以互相抵消，餘額仍然平。流水對帳先係屍檢同合規要求。

**Q：Gas 幣（ETH／BNB…）點對？**  
A：Gas 支出入**費用科目**，唔好當「憑空消失」。用 receipt **`gasUsed × effectiveGasPrice`**（L2 再加 **`l1Fee`**）加總快照區間內所有出金、歸集、內部轉帳；對番帳本 fee expense。熱錢包 ETH 少而 USDT 平，第一個懷疑就係 gas 未入帳。

## 小練習

**題：** Ethereum 每日對帳發現 USDT 鏈上比帳本多 1,250，ETH 熱錢包鏈上比帳本少 0.8 ETH。你點查？

**參考答案：**  
**USDT 多** → 先睇流水：有冇已上鏈但未入帳充值（確認數未夠／漏掃／無主充值例如合約地址打入、空投）；入暫記帳等認領，唔當收入。  
**ETH 少** → 最常見係 **gas 冇入帳**：加總快照區間內所有出金同歸集 tx 的 `gasUsed × effectiveGasPrice`（L2 再加 l1Fee），對番費用科目；再查已廣播未確認出金、gas 站打俾充值地址的 ETH（呢筆仍喺我方地址，要計入可控餘額）。扣除後仍少而解釋唔到 → 當熱錢包可能被盜，**P0**，暫停 ETH 出金、輪換密鑰流程。
